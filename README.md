# 🔴🔵 Ciberseguridad en foco 

### Un tópico que no podemos ignorar

###### Con fuentes de la Unidad Fiscal Especializada en Ciberdelincuencia (UFECI) y el Equipo de Respuesta ante Emergencias Informáticas nacional (CERT), esta exploración interactiva trae a la mesa un tema fundamental en nuestra vida diaria, la ciberseguridad. Se presenta la evolución en la cantidad de reportes y la variación de los tipos de incidentes a nivel ciudadano (UFECI) y a nivel gubernamental (CERT), con un pequeño auto diagnóstico para ayudar al usuario a orientarse respecto a sus hábitos de higiene digital en internet, y una sección especial para comparar la evolución de cada nivel frente a frente. El proyecto fue realizado en Python y desplegado en Streamlit como aplicación web, con su respectivo repositorio en GitHub como base del proyecto.
